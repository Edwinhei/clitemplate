# contracts —— 跨语言契约层

**这是整个仓库的枢纽。** 所有跨进程、跨语言的接口都在这里定义，
各语言从这里**生成**代码，而不是手写。

- `openapi/` — HTTP API 契约
- `proto/`   — gRPC / 事件契约

## 铁律

**消费方和提供方都只依赖契约，彼此不依赖。**

## 契约优先（contract-first）

**先改契约，再改实现。** 不允许从实现反向导出契约 ——
否则契约会跟着某一个实现漂移，其他语言的消费方就成了二等公民。

## 验收标准

**删掉 `apps/api` 整个目录，前端应该照样能编译过。**
编译不过 = 前端依赖了实现而不是契约。

## 流程（改契约时）

1. 改这里的定义
2. 跑 `pnpm gen:contracts` 重新生成各语言的代码
3. CI 用 `pnpm verify:contracts` 检查生成物是否新鲜 —— 不一致直接挂
